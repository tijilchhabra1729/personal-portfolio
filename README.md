# personal-portfolio

Single-file site: open `index.html`, or deploy the repo root to GitHub Pages / Vercel.

Content comes only from VERIFIED / USER-CONFIRMED entries in my master career database.
The "career graph" section is a graphify build over that database; its data is inlined in `index.html` (`#graph-data`).

After deploying, change `og:image` in `index.html` to the absolute URL of `og.png`; LinkedIn and Slack ignore relative image paths.
